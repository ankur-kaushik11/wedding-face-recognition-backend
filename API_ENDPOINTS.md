# API Endpoints Documentation

## Base URL
```
http://localhost:8000
```

## Authentication

### POST /auth/login
Login with event password and get JWT token.

**Request:**
```json
{
  "password": "WeddingPassword123",
  "role": "admin"
}
```

**Response:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "role": "admin"
}
```

**Status Codes:**
- 200: Success
- 401: Invalid password
- 400: Invalid role

---

## User Endpoints
All user endpoints require `Authorization: Bearer <token>` header.

### POST /user/scan-face
Upload a selfie and get matched photos.

**Rate Limit:** 5 requests per minute per IP

**Request:**
- Content-Type: multipart/form-data
- Body: file (image/jpeg or image/png, max 10MB)

**Response:**
```json
{
  "matched_photos": [
    {
      "id": "uuid",
      "drive_file_id": "google-drive-file-id",
      "drive_url": "https://drive.google.com/...",
      "day_name": "Day 1 - Mehndi",
      "indexed_at": "2026-01-30T10:00:00Z"
    }
  ],
  "total_matches": 10,
  "grouped_by_day": {
    "Day 1 - Mehndi": [...],
    "Day 2 - Wedding": [...]
  }
}
```

**Status Codes:**
- 200: Success
- 400: Invalid image file
- 401: Unauthorized
- 429: Rate limit exceeded

### GET /user/photos
Get all indexed photos, optionally filtered by day.

**Query Parameters:**
- `day` (optional): Filter by day name (e.g., "Day 1 - Mehndi")

**Response:**
```json
[
  {
    "id": "uuid",
    "drive_file_id": "google-drive-file-id",
    "drive_url": "https://drive.google.com/...",
    "day_name": "Day 1 - Mehndi",
    "indexed_at": "2026-01-30T10:00:00Z"
  }
]
```

**Status Codes:**
- 200: Success
- 401: Unauthorized

### POST /user/download-log
Log photo downloads for analytics.

**Request:**
```json
{
  "photo_ids": ["uuid1", "uuid2", "uuid3"]
}
```

**Response:**
```json
{
  "logged": true
}
```

**Status Codes:**
- 200: Success
- 401: Unauthorized

## Admin Endpoints
All admin endpoints require `Authorization: Bearer <token>` header with admin role.

### GET /admin/stats
Get system statistics.

**Response:**
```json
{
  "total_photos": 500,
  "total_users": 50,
  "total_scans": 120,
  "photos_by_day": {
    "Day 1 - Mehndi": 100,
    "Day 2 - Wedding": 150,
    "Day 3 - Reception": 250
  },
  "last_index_time": "2026-01-30T15:30:00Z"
}
```

**Status Codes:**
- 200: Success
- 401: Unauthorized
- 403: Forbidden (not admin)

### GET /admin/activity
Get activity logs with filtering.

**Query Parameters:**
- `limit` (default: 100): Maximum number of logs to return
- `user_id` (optional): Filter by specific user UUID

**Response:**
```json
[
  {
    "id": "uuid",
    "user_id": "user-uuid",
    "action": "face_scan",
    "photo_count": 10,
    "timestamp": "2026-01-30T15:30:00Z",
    "user_role": "user"
  }
]
```

**Status Codes:**
- 200: Success
- 401: Unauthorized
- 403: Forbidden (not admin)

### GET /admin/photos-summary
Get photos summary grouped by day.

**Response:**
```json
{
  "photos_by_day": [
    {
      "day_name": "Day 1 - Mehndi",
      "count": 100
    },
    {
      "day_name": "Day 2 - Wedding",
      "count": 150
    }
  ],
  "total_photos": 250
}
```

**Status Codes:**
- 200: Success
- 401: Unauthorized
- 403: Forbidden (not admin)

### POST /admin/reindex
Trigger photo indexing from Google Drive.

**Request:**
```json
{
  "force": false
}
```
- `force: false` - Index only new photos
- `force: true` - Reindex all photos

**Response:**
```json
{
  "message": "Indexing complete. Processed 500 photos.",
  "total_photos_indexed": 500,
  "new_photos_indexed": 50,
  "photos_by_day": {
    "Day 1 - Mehndi": 10,
    "Day 2 - Wedding": 20,
    "Day 3 - Reception": 20
  },
  "indexing_time_seconds": 120.5
}
```

**Status Codes:**
- 200: Success
- 401: Unauthorized
- 403: Forbidden (not admin)
- 500: Indexing error

## Authentication Flow

1. **User logs in** with event password and role:
   ```bash
   curl -X POST http://localhost:8000/auth/login \
     -H "Content-Type: application/json" \
     -d '{"password": "WeddingPassword123", "role": "user"}'
   ```

2. **Store the token** from response:
   ```json
   {"access_token": "eyJhbGci...", "token_type": "bearer", "role": "user"}
   ```

3. **Use token for authenticated requests**:
   ```bash
   curl -X GET http://localhost:8000/user/photos \
     -H "Authorization: Bearer eyJhbGci..."
   ```

---

## Error Responses

All endpoints may return error responses in this format:

```json
{
  "detail": "Error message"
}
```

Common status codes:
- 400: Bad Request (validation error)
- 401: Unauthorized (missing or invalid token)
- 403: Forbidden (insufficient permissions)
- 404: Not Found
- 429: Too Many Requests (rate limit exceeded)
- 500: Internal Server Error

---

## Rate Limiting

- **Face Scan Endpoint:** 5 requests per minute per IP address
- Rate limit headers are included in responses
- Exceeding the limit returns 429 status code

---

## File Upload Constraints

- **Max file size:** 10MB (configurable via MAX_UPLOAD_SIZE_MB)
- **Allowed formats:** JPEG, PNG
- **Face detection:** At least one face must be detected in uploaded images

## Testing with cURL

### Login as Admin
```bash
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"password": "WeddingPassword123", "role": "admin"}'
```

### Get Stats (Admin)
```bash
curl -X GET http://localhost:8000/admin/stats \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Scan Face (User)
```bash
curl -X POST http://localhost:8000/user/scan-face \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@selfie.jpg"
```

### Reindex Photos (Admin)
```bash
curl -X POST http://localhost:8000/admin/reindex \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"force": false}'
```
